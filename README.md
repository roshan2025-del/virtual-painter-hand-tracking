# Virtual Painter Using Hand Tracking

A computer vision project that allows users to draw on a virtual canvas using hand gestures and a webcam.

## Features

* Real-time hand tracking using a webcam.
* Hand landmark detection.
* Drawing using the index finger tip.
* Virtual canvas for gesture-based drawing.

## Technologies Used

* Python
* OpenCV
* NumPy
* MediaPipe (hand tracking)

## Project Files

* `virtual_painter.py` — Main application.
* `hand_tracking_module.py` — Hand detection and tracking.
* `test_camera.py` — Camera testing.
* `test_hands.py` — Hand detection testing.
* `test_module.py` — Module testing.

## How to Run

1. Install Python.
2. Install the required libraries:
   `pip install opencv-python mediapipe numpy`
3. Run the application:
   `python virtual_painter.py`

Connect a webcam before running the application.

## Project Background

Developed as a second-year college project to explore computer vision and real-time hand gesture interaction.
